MA FERME CONNECTÉE — V24 (paquet PWA avec logo intégré)

CONTENU
- index.html : application de gestion avec le logo fourni intégré dans l’en-tête et l’accueil.
- logo-ma-ferme-connectee.png : logo complet dans l’application.
- logo-symbole.png : symbole utilisé dans l’en-tête.
- manifest.webmanifest : nom, couleurs et paramètres d’installation.
- service-worker.js : cache de l’interface et des images de marque uniquement.
- icon-192.png / icon-512.png : icônes d’installation créées à partir du symbole du logo.

IMPORTANT
- Ce paquet est une copie de travail. Il ne remplace pas V12, V21/V22/V23 ni le site publié.
- Les données du navigateur ne sont pas transférées automatiquement lors d’un changement d’adresse.
- L’installation PWA nécessite une adresse HTTPS (par exemple GitHub Pages). L’ouverture directe via file:// ne permet pas l’installation complète.
- Le service worker ne met pas en cache les réponses Supabase, jetons ou données privées.
- L’envoi général Supabase reste désactivé dans cette version de test. La synchronisation Santé demeure ciblée et doit être testée après publication.

PUBLICATION PRUDENTE
1. Décompressez le ZIP dans un nouveau dossier sur l’ordinateur.
2. Conservez une copie de sauvegarde du site publié et téléchargez une sauvegarde JSON depuis l’application actuelle.
3. Dans le dépôt GitHub bouesso1997/ma-ferme-connectee, ajoutez les fichiers du paquet à la racine du site : index.html, manifest.webmanifest, service-worker.js, icon-192.png, icon-512.png, logo-symbole.png et logo-ma-ferme-connectee.png.
4. Ne supprimez pas les autres fichiers ou sauvegardes. Publiez seulement après avoir vérifié la copie.
5. Ouvrez le site en HTTPS et vérifiez le logo sur téléphone et ordinateur avant d’adopter la version.
